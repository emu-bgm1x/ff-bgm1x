VisualBoyAdvance-M 2.2.3 수정판 (ff-bgm1x) 2026.11.20 - 배속 중에도 BGM 1배속 유지

[실행]
  visualboyadvance-m.exe 를 실행하고 File -> Open 으로 ROM 을 엽니다. (ROM 은 포함되어 있지 않습니다)
  공식 VBA-M 2.2.3 과 같은 소스에 이 기능만 더했습니다. 설정은 공식판과 같은 자리(vbam.ini)에 저장됩니다.
  배속(Speed/터보) 버튼과 배속 설정은 공식 VBA-M 과 같습니다.
  배속 설정 창(Speedup / Turbo...)의 "Mute Sound" 가 켜져 있으면 배속 중에 1배속 BGM 은 나오지만
  게임 속도로 나는 소리는 들리지 않습니다. 모두 들으려면 "Mute Sound" 를 끄세요.

[추가된 메뉴] Options -> Audio 아래쪽
  Keep BGM at 1x speed (ff-bgm1x)            BGM 1배속 유지 (기본값 켜짐)
  Keep sound effects at 1x speed (ff-bgm1x)  효과음 1배속 (기본값 켜짐)
  Fast forward during cutscenes (ff-bgm1x)   연출 중에도 배속 (기본값 꺼짐)
  Read songs from RAM (ff-bgm1x)             RAM 곡 읽기 (기본값 꺼짐)
  Sound classification... (ff-bgm1x)         소리 분류 창

[추가된 설정] Options -> Audio -> Configure... (사운드 설정 창)
  SFX volume (1x)                            1배속으로 내는 GBA 효과음의 볼륨 (0~256, 기본값 256 = 원래 크기)

  설정은 vbam.ini 의 [Sound] 에 저장됩니다 (FfbgmBgm1x, FfbgmSfx1x, FfbgmFfCutscenes, FfbgmSfxVolume, FfbgmRamSongs).

[소리 분류 창] 메뉴 Options -> Audio -> "Sound classification... (ff-bgm1x)"
  단축키는 VBA-M 의 단축키 설정에서 이 메뉴에 직접 지정합니다 (기본 키 없음).
  - 창이 앞에 있으면 게임이 일시정지되고, 에뮬레이터 창을 누르면 게임이 진행되며 나오는 소리가 목록에 모입니다.
    "BGM 1배속 유지" 가 꺼져 있어도 창이 열려 있으면 모읍니다.
  - 소리마다 분류(BGM / 팡파레·대사 / 연출 / 효과음 / 아무것도 아님 / 자동), 볼륨(0~200%),
    재생(롬에서 직접 불러와 재생, 재생/일시정지·중지), 기본값으로(분류·볼륨) 를 할 수 있습니다.
    에뮬레이터의 자동 판단이 게임과 맞지 않을 때 직접 고치는 기능입니다.
  - 이름·지정·볼륨 칸을 두 번 클릭하면 바꾸는 창이 뜨고, 그 밖의 칸을 두 번 클릭하면 재생합니다.
    칸 제목을 누르면 그 칸으로 정렬합니다. GBA 곡은 롬에 이름이 없어 "곡 번호 (주소)" 로 나오며 이름을 붙일 수 있습니다.
  - 볼륨은 1배속으로 내는 소리와 원본 그대로 나오는 소리 모두에 적용되고, 바꾸는 즉시 지금 나오는 소리에도 적용됩니다.
    GB/GBC 원본 소리의 볼륨을 위해 GB 소리 칩 에뮬레이션(Gb_Apu)이 채널마다 합성기를 따로 쓰도록 바꿨습니다.
  - 정한 내용은 실행 파일 옆 ff-bgm1x-sounds\<게임 코드>.txt 에 바로 저장되고,
    내보내기·가져오기로 다른 사람과 주고받을 수 있습니다. mGBA 수정판과 같은 파일을 씁니다.
  - 재생은 따로 연 오디오 출력으로 내므로 게임이 일시정지돼 있어도 들립니다.
  - 창이 닫혀 있으면 소리를 모으지 않습니다.
  - 목록에 나오는 소리: GBA 는 곡, 울음소리 전체 / GB·GBC 는 곡, 효과음, 울음소리 전체.

[울음소리 전체와 RAM 곡 읽기, 연출]
  - 울음소리 전체: 게임이 RAM 에 만들어 내는 곡(GBA)과 울음소리 표시가 켜진 효과음 채널(GB/GBC)을 한 항목으로 묶습니다.
    기본값은 아무것도 아님(원본 그대로)입니다. 분류 창에서 연출로 정하면 나오는 동안 배속을 멈추고,
    효과음(또는 BGM·팡파레)으로 정하면 "Read songs from RAM" 이 켜져 있을 때 1배속으로 냅니다.
  - RAM 곡 읽기 (메뉴 Options -> Audio -> "Read songs from RAM (ff-bgm1x)", 기본값 꺼짐): 켜면, 1배속으로 정한 RAM 곡을
    시작하는 순간의 게임 RAM 을 복사해 1배속으로 냅니다 (GB/GBC 는 원본 채널의 음높이·길이를 읽음).
  - GB/GBC: 분류 창에서 연출로 정한 소리가 나오는 동안 배속을 멈춥니다 ("연출 중에도 배속" 이 꺼져 있을 때).
  - GBA: 곡 목록에 없는 플레이어(효과음 전용으로 따로 연 플레이어)도 찾습니다. 분류 창에서 정하기 전에는 원본 그대로입니다.

[동작 방식]
  mGBA 수정판과 같은 재생기(같은 코드)를 씁니다.
  GBA 게임: MP2K(Sappy) 사운드 엔진을 쓰는 게임에서 원본 BGM 을 무음 처리하고,
            같은 곡을 ROM 에서 읽어 내장 재생기로 항상 1배속으로 재생합니다.
            팡파레(반복 없는 12초 이하 곡)는 1배속으로 끝까지, 연출 곡(반복 없는 12초 넘는 곡)이 나오는 동안은
            "연출 중에도 배속" 이 꺼져 있으면 배속하지 않습니다. 반복 없는 효과음도 1배속으로 끝까지 냅니다.
  GB/GBC 게임: 지원하는 사운드 엔진(GB 2세대 사운드 엔진)이면
            게임의 사운드 엔진을 옮긴 자체 재생기로 같은 곡을 1배속으로 내고,
            원본의 음악 채널만 끕니다. 효과음(대화음, 메뉴음, 아이템 받는 소리 등)과 낮은 체력 경고음도 1배속입니다.
  지원하지 않는 엔진의 게임은 아무것도 바꾸지 않습니다 (원래 VBA-M 과 동일).
  - 1배속 소리는 VBA-M 의 오디오 출력과 따로 연 출력 스트림으로 나옵니다 (오디오 설정에서 고른 장치와 같은 장치).
    그래서 배속 배율과 관계없이 실제 시간으로 납니다.
  - 녹화(Tools -> Record)에도 1배속 소리가 섞입니다. 방송용 화면 녹화 프로그램(OBS 등)도 그대로 녹음됩니다.

[알려진 제약]
  - GB/GBC 의 1배속 BGM 은 자체 재생기의 GB 사운드 합성으로 나오므로, VBA-M 원래 GB 소리와 음색이 조금 다를 수 있습니다.
  - GB/GBC 게임에는 팡파레 처리와 "SFX volume (1x)" 가 적용되지 않습니다.
  - GBA: 페이드아웃, 울음소리 중 볼륨 감소 같은 연출은 반영되지 않습니다.
  - 곡이 시작되는 첫 프레임에 원본 BGM 이 짧게 들릴 수 있습니다.
  - 울음소리 전체를 1배속으로 내면 배속 중에는 화면(등장 장면 등)보다 늦게 끝납니다.
    화면과 맞추려면 연출로 정해 그동안 배속을 멈춥니다.
  - 원본 그대로 나오는 GBA 소리의 볼륨을 100% 보다 크게 하면, 게임 트랙 볼륨 계산이 넘치지 않게 위쪽을 잘라
    원래 큰 소리는 거의 커지지 않을 수 있습니다.
  - 서명되지 않은 실행 파일이라 Windows 가 실행을 막거나 경고할 수 있습니다.

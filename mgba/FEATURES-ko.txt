mGBA 0.10.5 수정판 (ff-bgm1x) 2026.11.20 - 배속 중에도 BGM 1배속 유지

[기능]
  - BGM 1배속 유지: 배속 중에도 BGM 을 1배속으로 냅니다. 배속 중에 끄면 원본 BGM 이 바로 나옵니다
    (지금 곡을 처음부터 다시 재생).
  - 효과음 1배속: 반복 없는 효과음(메뉴 선택음, 대화음, 문 여닫는 소리 등)도 배속 중에 1배속으로 끝까지 냅니다.
    GB/GBC(지원하는 사운드 엔진)는 효과음(대화음, 메뉴음, 아이템 받는 소리 등)을 게임의 효과음 루틴으로 1배속으로 냅니다.
    낮은 체력 경고음(삐-삐)도 배속 중에 1배속 박자로 냅니다.
  - GBA 팡파레: 반복 없는 12초 이하 곡은 배속 중에도 1배속으로 끝까지 재생합니다. 게임이 다음 곡을 시작하면 그때 끊습니다.
  - GBA 연출 곡: 반복 없는 12초 넘는 곡이 나오는 동안 배속을 잠시 멈춥니다 ("연출 중에도 배속" 이 꺼져 있을 때).
    GB/GBC 는 분류 창에서 연출로 정한 소리가 나오는 동안 배속을 멈춥니다.
  - GBA: 곡 목록에 없는 플레이어(효과음 전용으로 따로 연 플레이어)도 찾습니다. 분류 창에서 정하기 전에는 원본 그대로입니다.
  - 효과음 볼륨: Tools -> Settings -> Audio/Video 의 빨리 감기 볼륨 아래 "효과음 볼륨" 슬라이더.
    "효과음 1배속" 으로 1배속으로 내는 GBA 효과음의 볼륨만 바꿉니다 (기본값 최대 = 원래 크기).
    GB/GBC 게임에는 적용되지 않습니다 (효과음과 음악이 한 재생기에서 섞여 나오기 때문입니다).
    옆의 "무음" 을 체크하면 그 효과음을 끕니다. 설정은 config.ini 의 bgmSfxVolume (0~256), bgmSfxMute 에 저장됩니다.
  - 울음소리 전체: 게임이 RAM 에 만들어 내는 곡(GBA)과 울음소리 표시가 켜진 효과음 채널(GB/GBC)을 한 항목으로 묶습니다.
    기본값은 아무것도 아님(원본 그대로)입니다. 분류 창에서 연출로 정하면 나오는 동안 배속을 멈추고,
    효과음(또는 BGM·팡파레)으로 정하면 "RAM 곡 읽기" 가 켜져 있을 때 1배속으로 냅니다.
  - RAM 곡 읽기 (기본값 꺼짐): 켜면, 1배속으로 정한 RAM 곡을 시작하는 순간의 게임 RAM 을 복사해 1배속으로 냅니다
    (GB/GBC 는 원본 채널의 음높이·길이를 읽음).
  - 공식 mGBA 배포본처럼 mGBA.exe 하나로 실행됩니다 (DLL 폴더 없음).
    portable.ini 가 있어 설정은 실행 파일 옆(config.ini 등)에 저장됩니다.

[소리 분류 창] 메뉴 Audio/Video -> "소리 분류..."
  단축키는 Tools -> Settings -> Shortcuts 에서 "소리 분류..." 에 직접 지정합니다 (기본 키 없음).
  - 창이 앞에 있으면 게임이 일시정지되고, 에뮬레이터 창을 누르면 게임이 진행되며 나오는 소리가 목록에 모입니다.
    창을 열 때 이미 나오고 있던 소리도 목록에 들어갑니다. "BGM 1배속 유지" 가 꺼져 있어도 창이 열려 있으면 모읍니다.
  - 소리마다 분류(BGM / 팡파레·대사 / 연출 / 효과음 / 아무것도 아님 / 자동), 볼륨(0~200%),
    재생(롬에서 직접 불러와 재생, 재생/일시정지·중지), 기본값으로(분류·볼륨) 를 할 수 있습니다.
    에뮬레이터의 자동 판단이 게임과 맞지 않을 때 직접 고치는 기능입니다.
  - 이름·지정·볼륨 칸을 두 번 클릭하면 그 자리에서 바꾸고, 그 밖의 칸을 두 번 클릭하면 재생합니다.
    GBA 곡은 롬에 이름이 없어 "곡 번호 (주소)" 로 나오며, 이름 칸에서 이름을 붙일 수 있습니다 (비우면 원래 이름).
  - 볼륨은 1배속으로 내는 소리와 원본 그대로 나오는 소리 모두에 적용되고, 바꾸는 즉시 지금 나오는 소리에도 적용됩니다.
    "효과음 볼륨" 슬라이더와 곱해서 적용됩니다.
  - 정한 내용은 실행 파일 옆 ff-bgm1x-sounds\<게임 코드>.txt 에 바로 저장되고,
    내보내기·가져오기로 다른 사람과 주고받을 수 있습니다. VBA-M 수정판과 같은 파일을 씁니다.
  - 창이 닫혀 있으면 소리를 모으지 않습니다.
  - 목록에 나오는 소리: GBA 는 곡, 울음소리 전체 / GB·GBC 는 곡, 효과음, 울음소리 전체.

[실행]
  mGBA.exe 를 실행하고 ROM 을 엽니다. (ROM 은 포함되어 있지 않습니다)
  메뉴 Audio/Video -> "BGM 1배속 유지" 가 체크되어 있으면 동작합니다 (기본값 켜짐).
  메뉴 Audio/Video -> "연출 중에도 배속" 을 켜면 연출 곡이 나올 때도 배속을 유지합니다 (기본값 꺼짐).
  메뉴 Audio/Video -> "효과음 1배속" 을 끄면 효과음은 원본처럼 게임 속도로 납니다 (기본값 켜짐).
  메뉴 Audio/Video -> "RAM 곡 읽기" 는 울음소리 전체 등 RAM 곡을 1배속으로 낼 때 켭니다 (기본값 꺼짐).
  메뉴 Audio/Video -> "소리 분류..." 로 소리 분류 창을 엽니다.
  배속: Tab (누르는 동안), Shift+Tab (켜기/끄기) - mGBA 기본 키

[동작 방식]
  GBA 게임: MP2K(Sappy) 사운드 엔진을 쓰는 게임에서 원본 BGM 을 무음 처리하고,
            같은 곡을 ROM 에서 읽어 내장 재생기로 항상 1배속으로 재생합니다.
  GB/GBC 게임: 지원하는 사운드 엔진(GB 2세대 사운드 엔진)이면
            게임의 사운드 엔진을 옮긴 자체 재생기로 같은 곡을 1배속으로 내고, 원본의 음악 채널만 끕니다.
  지원하지 않는 엔진의 게임은 아무것도 바꾸지 않습니다 (원래 mGBA 와 동일).
  - 실시간 소리: 배속과 관계없이 BGM 1배속
  - Audio/Video -> Record A/V: 녹화 파일은 게임 진행 시간 기준으로 BGM 이 섞입니다

[알려진 제약]
  - GBA: 페이드아웃, 울음소리 중 볼륨 감소 같은 연출은 반영되지 않습니다.
  - 곡이 시작되는 첫 프레임에 원본 BGM 이 짧게 들릴 수 있습니다.
  - 배속 중에는 게임이 곡을 더 빨리 넘기므로, 팡파레가 끝나기 전에 게임이 다음 곡을 시작하면 팡파레가 잘립니다.
  - GB/GBC 게임에는 팡파레 처리가 적용되지 않습니다.
  - 효과음 1배속(GBA): 반복하는 효과음은 게임 속도 그대로입니다.
  - 효과음 1배속(GBA): 배속 중 효과음이 1배속으로 아직 나오는 동안 같은 자리(플레이어)에서 새로 나는 효과음은 건너뜁니다.
  - 효과음 1배속(GB/GBC): 배속 중 효과음이 1배속으로 아직 나오는 동안에는 우선순위가 더 높은 효과음만 끊고 내고,
    나머지는 건너뜁니다 (게임의 효과음 우선순위와 같은 규칙).
  - 효과음 1배속(GB/GBC): 스테레오 설정에서 좌우로 나뉘는 효과음은 가운데로 날 수 있습니다.
  - 울음소리 전체를 1배속으로 내면 배속 중에는 화면(등장 장면 등)보다 늦게 끝납니다.
    화면과 맞추려면 연출로 정해 그동안 배속을 멈춥니다.
  - 원본 그대로 나오는 GBA 소리의 볼륨을 100% 보다 크게 하면, 게임 트랙 볼륨 계산이 넘치지 않게 위쪽을 잘라
    원래 큰 소리는 거의 커지지 않을 수 있습니다.
  - 서명되지 않은 실행 파일이라 Windows 가 실행을 막거나 경고할 수 있습니다.

mGBA 0.10.5 수정판 (ff-bgm1x) 버전 4 - 배속 중에도 BGM 1배속 유지

[v4 에서 바뀐 점]
  - GBA: "효과음 1배속" 이 켜져 있을 때 배속 중에 게임 원본 효과음이 1배속 효과음과 겹쳐 들리던 문제를 고쳤습니다
    (예: 벽에 부딪히는 소리를 계속 낼 때 원본 소리가 계속 나면서 1배속 소리도 같이 남).
    원인: 효과음이 GBA 의 PSG(CGB) 채널을 쓰면, 게임이 소리를 시작한 뒤 트랙 볼륨을 0 으로 바꿔도
    이미 시작된 소리가 몇 프레임 더 울렸습니다. 배속 중에는 이 소리가 아주 빠르게 반복됩니다.
    이제 1배속으로 대신 내는 음악·효과음이 쓰는 PSG 채널은 에뮬레이터 출력에서 바로 끕니다
    (게임 메모리와 게임 진행은 건드리지 않습니다).
    Audio/Video 메뉴의 오디오 채널 켜기/끄기와 같은 기능을 쓰므로, 대체 중에는 그 채널이 잠시 꺼집니다.

[v3 에서 바뀐 점]
  - 효과음 볼륨: Tools -> Settings -> Audio/Video 의 빨리 감기 볼륨 아래에 "효과음 볼륨" 슬라이더를 추가했습니다.
    "효과음 1배속" 으로 1배속으로 내는 GBA 효과음의 볼륨만 바꿉니다 (기본값 최대 = 원래 크기).
    GB/GBC 게임에는 적용되지 않습니다 (효과음과 음악이 한 재생기에서 섞여 나오기 때문입니다).
    옆의 "무음" 을 체크하면 그 효과음을 끕니다.
    설정은 config.ini 의 bgmSfxVolume (0~256), bgmSfxMute 에 저장됩니다.

[v2 에서 바뀐 점]
  - GBA: 팡파레(반복 없는 12초 이하 곡)는 배속 중에도 1배속으로 끝까지 재생합니다.
         게임이 다음 곡을 시작하면 그때 끊습니다.
  - GBA: 메뉴 Audio/Video -> "연출 중에도 배속" 추가 (기본값 꺼짐).
         꺼져 있으면 연출 곡(반복 없는 12초 넘는 곡)이 나오는 동안 배속을 잠시 멈춥니다.
  - GBA: 메뉴 Audio/Video -> "효과음 1배속" 추가 (기본값 켜짐).
         반복 없는 효과음(메뉴 선택음, 대화음, 문 여닫는 소리 등)도 배속 중에 1배속으로 끝까지 냅니다.
  - GB/GBC(포켓몬 금·은·크리스탈 엔진): "효과음 1배속" 이 적용됩니다.
         효과음(대화음, 메뉴음, 아이템 받는 소리 등)을 게임의 효과음 루틴으로 1배속으로 냅니다. 울음소리는 게임 속도 그대로입니다.
  - GBA: 배속 중에 "BGM 1배속 유지" 를 끄면 원본 BGM 이 바로 나옵니다 (지금 곡을 처음부터 다시 재생).
         이전에는 다른 곡으로 넘어갈 때까지 BGM 이 나오지 않았습니다.
  - 이름을 gba-bgm 에서 ff-bgm1x 로 바꿨습니다.
  - 공식 mGBA 배포본처럼 mGBA.exe 하나로 실행됩니다 (DLL 폴더 없음).
    portable.ini 가 있어 설정은 실행 파일 옆(config.ini 등)에 저장됩니다. 이전 판의 설정은 이어지지 않습니다.

[실행]
  mGBA.exe 를 실행하고 ROM 을 엽니다. (ROM 은 포함되어 있지 않습니다)
  메뉴 Audio/Video -> "BGM 1배속 유지" 가 체크되어 있으면 동작합니다 (기본값 켜짐).
  메뉴 Audio/Video -> "연출 중에도 배속" 을 켜면 연출 곡이 나올 때도 배속을 유지합니다 (기본값 꺼짐).
  메뉴 Audio/Video -> "효과음 1배속" 을 끄면 효과음은 원본처럼 게임 속도로 납니다 (기본값 켜짐).
  배속: Tab (누르는 동안), Shift+Tab (켜기/끄기) - mGBA 기본 키

[동작 방식]
  GBA 게임: MP2K(Sappy) 사운드 엔진을 쓰는 게임에서 원본 BGM 을 무음 처리하고,
            같은 곡을 ROM 에서 읽어 내장 재생기로 항상 1배속으로 재생합니다.
  GB/GBC 게임: 지원하는 사운드 엔진(현재 포켓몬 금·은·크리스탈 엔진)이면
            게임 자체의 음악 코드를 별도로 1배속 실행해 BGM 을 만들고, 원본의 음악 채널만 끕니다.
  지원하지 않는 엔진의 게임은 아무것도 바꾸지 않습니다 (원래 mGBA 와 동일).
  - 실시간 소리: 배속과 관계없이 BGM 1배속
  - Audio/Video -> Record A/V: 녹화 파일은 게임 진행 시간 기준으로 BGM 이 섞입니다

[알려진 제약]
  - GBA: 페이드아웃, 울음소리 중 볼륨 감소 같은 연출은 반영되지 않습니다.
  - 곡이 시작되는 첫 프레임에 원본 BGM 이 짧게 들릴 수 있습니다.
  - 배속 중에는 게임이 곡을 더 빨리 넘기므로, 팡파레가 끝나기 전에 게임이 다음 곡을 시작하면 팡파레가 잘립니다.
  - GB/GBC 게임에는 팡파레 처리와 "연출 중에도 배속" 이 적용되지 않습니다.
  - 효과음 1배속(GBA): 포켓몬 울음소리처럼 게임이 RAM 에서 만들어 내는 소리와 반복하는 효과음은 게임 속도 그대로입니다.
  - 효과음 1배속(GBA): 배속 중 효과음이 1배속으로 아직 나오는 동안 같은 자리(플레이어)에서 새로 나는 효과음은 건너뜁니다.
  - 효과음 1배속(GB/GBC): 배속 중 효과음이 1배속으로 아직 나오는 동안에는 우선순위가 더 높은 효과음만 끊고 내고,
    나머지는 건너뜁니다 (게임의 효과음 우선순위와 같은 규칙).
  - 효과음 1배속(GB/GBC): 스테레오 설정에서 좌우로 나뉘는 효과음은 가운데로 날 수 있습니다.
  - 서명되지 않은 실행 파일이라 Windows 가 실행을 막거나 경고할 수 있습니다.

DeSmuME 0.9.13 수정판 (ff-bgm1x) 2026.11.20 - 배속 중에도 BGM 1배속 유지

[실행]
  DeSmuME_0.9.13_x64.exe 를 실행하고 File -> Open ROM 으로 ROM 을 엽니다. (ROM 은 포함되어 있지 않습니다)
  공식 DeSmuME 0.9.13 과 같은 소스에 이 기능만 더했습니다. 설정 파일(desmume.ini)은 실행 파일 옆에 만들어집니다.
  공식 배포본처럼 게임 DB(desmume.ddb)를 실행 파일 옆에 두세요.
  Microsoft Visual C++ 재배포 패키지(2015~2022, x64)가 필요할 수 있습니다 (공식 DeSmuME 와 같음).
  배속 키는 공식 DeSmuME 와 같습니다: Tab (누르고 있는 동안), Fast Forward Toggle (기본 키 없음).
  키는 Config -> Hotkey Config 에서 바꿉니다.
  Fast Forward Toggle 에 Tab 이 들어간 조합(예: Shift+Tab)을 쓰면, 키를 뗄 때 Tab 의 "뗌" 이 같이 처리되어
  배속이 바로 꺼집니다. Tab 이 들어가지 않는 키를 쓰세요.

[추가된 메뉴] Config 메뉴, Emulation Settings 위
  Fast forward speed
    2x / 3x / 4x / 6x / 8x       배속을 원래 속도(100%)의 N배로 제한 (화면은 N프레임 중 1프레임만 그림)
    Unlimited                     공식 DeSmuME 와 같이 최대 속도 (기본값)
    배속 중에는 공식 DeSmuME 와 같이 + / - 속도 설정을 쓰지 않습니다.
  ff-bgm1x (1x audio)
    Keep BGM at 1x speed          BGM 1배속 유지 (기본값 켜짐)
    Keep sound effects at 1x      효과음 1배속 (기본값 켜짐)
    Fast forward during cutscenes 연출 중에도 배속 (기본값 꺼짐)
    Sound classification...       소리 분류 창 (아래 [소리 분류 창])

[추가된 설정] Config -> Sound Settings 아래쪽
  SFX Volume (1x)                 1배속으로 내는 효과음의 볼륨 (0~256, 기본값 256 = 원래 크기)
                                  움직이면 바로 적용, Cancel 이면 원래 값

[추가된 단축키] Config -> Hotkey Config (기본값 없음)
  Keep BGM at 1x Toggle
  Fast Forward During Cutscenes Toggle
  Sound Classification Window

  설정은 desmume.ini 의 [ff-bgm1x] 에 저장됩니다
  (Bgm1x, Sfx1x, FfCutscenes, SfxVolume, FastForwardSpeed).

[소리 분류 창] Config 메뉴 -> ff-bgm1x (1x audio) -> Sound classification...
  게임에서 나오는 소리를 BGM / 연출 / 효과음 등으로 어떻게 다룰지 직접 정하는 창입니다.
  단축키: Config -> Hotkey Config -> "Sound Classification Window" (기본값 없음, 직접 지정)
  - 이 창이 앞에 있으면 게임이 일시정지됩니다. 에뮬레이터 창을 누르면 게임이 진행되며,
    그동안 나오는 소리(시퀀스, 효과음 묶음 안의 소리, 스트림)가 목록에 모입니다.
    창을 열 때 이미 나오고 있던 소리도 목록에 들어갑니다. "Keep BGM at 1x speed" 가 꺼져 있어도 모읍니다.
  - 재생 / 일시정지, 중지: 고른 소리를 롬에서 직접 불러와 들려줍니다 (게임이 일시정지돼 있어도 들립니다).
  - 분류: 자동(기본값) / BGM / 팡파레·대사 / 연출 / 효과음 / 아무것도 아님.
      BGM          1배속으로 냅니다 (반복 곡처럼)
      팡파레·대사  1배속으로 끝까지 냅니다
      연출          원본 그대로 두고, 나오는 동안 배속을 멈춥니다 ("연출 중에도 배속" 을 켜면 배속)
      효과음        1배속으로 냅니다 ("Keep sound effects at 1x speed" 를 따릅니다)
      아무것도 아님 원본 그대로 (게임 속도)
  - 볼륨: 그 소리의 볼륨 (0~200%, 100% = 원래 크기). 1배속으로 내는 소리와 원본 그대로 나오는 소리 모두에 적용되고,
    바꾸는 즉시 지금 나오는 소리에도 적용됩니다. 원본 그대로 나오는 시퀀스 소리는 드라이버가 최대 음량을 넘지 않게 잘라
    100% 보다 크게 하면 원래 소리 크기에 따라 덜 커질 수 있습니다.
  - 기본값으로: 그 소리의 분류와 볼륨을 자동 판단으로 되돌립니다.
  - 지정 칸·볼륨 칸을 두 번 누르면 그 자리에서 바꾸고, 그 밖의 칸을 두 번 누르면 재생합니다.
  - 정한 내용은 바로 실행 파일 옆 ff-bgm1x-sounds\<게임 코드>.txt 에 저장되고, 다음에 켜도 목록에 보입니다.
    내보내기 / 가져오기로 다른 사람과 주고받을 수 있습니다. melonDS 수정판과 DeSmuME 수정판은 같은 파일을 씁니다.
  - 창이 닫혀 있으면 목록에 모으지 않습니다 (성능에 영향 없음).
  - 재생 소리는 Windows 기본 출력 장치로 나옵니다.
[동작 방식]
  melonDS 수정판과 같은 방식입니다.
  닌텐도 표준 사운드 드라이버(SDAT: SSEQ/SBNK/SWAR)를 쓰는 DS 게임이 대상입니다.
  게임이 음악을 시작하라고 사운드 CPU 에 보내는 명령을 지켜보다가, 원본 음악은 소리만 끄고
  같은 곡을 내장 재생기로 실제 시간에 맞춰 연주합니다.
  - 반복되는 곡(필드, 배틀 등)       : 배속과 관계없이 1배속
  - 팡파레(반복 없고 12초 이하)      : 1배속으로 끝까지 연주하고, 멈춰 있던 곡은 그 뒤에 이어집니다.
  - 연출 곡(반복 없고 12초보다 긴 곡) : 바꾸지 않습니다. "연출 중에도 배속"이 꺼져 있으면
                                       이 곡이 나오는 동안에는 배속을 걸어도 1배속으로 진행합니다.
                                       (이때는 + / - 로 정한 평소 속도로 돕니다)
  - 효과음                           : 음악이 아닌 반복 없는 시퀀스(SSEQ) 소리를 1배속으로 끝까지 냅니다.
                                       효과음 묶음(SSAR)으로 내는 소리, 반복하는 효과음, 울음소리(SEQ_PV...)는
                                       게임 속도 그대로입니다 (소리 분류 창에서 효과음 등으로 바꿀 수 있습니다).
  - 상태 저장을 불러왔을 때 같은 반복 곡이 계속 나오면, 1배속 연주를 끊지 않고 그대로 이어 갑니다.
    그 밖의 경우(다른 곡, 기능을 다시 켬)에는 게임이 연주 중이던 곡을 같은 위치부터 이어 받습니다.
  - 같은 효과음을 짧은 간격으로 되풀이하면(낮은 체력 경고음, 발소리 등) 그 간격도 1배속으로 맞춥니다.
    배속 중에는 게임에서 울린 횟수보다 적게 울립니다.
  - 스트림 곡(STRM)                 : 기본은 연출입니다. 게임이 롬에서 STRM 을 읽는 동안 "연출 중에도 배속"이
                                       꺼져 있으면 1배속으로 진행합니다. 소리 분류 창에서 BGM 등으로 정하면
                                       원본 스트림 채널을 끄고 같은 파일을 롬에서 직접 풀어 1배속으로 냅니다.
  BGM 1배속은 실제 시간에 맞춰 내므로, + 키로 평소 속도를 올려도 1배속으로 납니다.
  표준 드라이버를 쓰지 않는 게임에서는 아무것도 바꾸지 않습니다.

[알려진 제약]
  - melonDS 수정판의 알려진 제약(내장 재생기 소리 차이, 일부 명령 미반영 등)이 같이 있습니다.
  - 시작 영상 곡이나 타이틀 곡이 연출 곡인 게임은 타이틀 화면에 머무는 동안에도 배속이 걸리지 않습니다
    ("Fast forward during cutscenes" 를 켜면 걸립니다).
  - 서명되지 않은 실행 파일이라 Windows 가 실행을 막거나 경고할 수 있습니다.

[공식 DeSmuME 0.9.13 과 다른 점 (BGM 기능 외)]
